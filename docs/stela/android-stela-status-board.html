  • Rejected bearer → My Files silently emptyAgreed 2026-09-18

    Since stela v0.97.0 a token FusionAuth marks inactive gets 401 on every authenticated V2 call, but /children treats it as an anonymous caller and answers 200 {"items": []}. Client guard (VSP-1842): StelaAuthState.isBearerRejected is set on any Stela 401 that carried a bearer and cleared when /v2/archives answers 2xx; every flag-gated V2 read runs V1 while set.
